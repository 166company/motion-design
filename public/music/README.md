# Musiqi

Bu qovluğa arxa fon musiqisi at (`.mp3`). Agent hər video üçün birini seçir.

## Haradan (pulsuz, kartsız, kommersiya üçün təhlükəsiz)

1. **Instagram Sound Collection** — ən təhlükəsiz variant.
   Instagram tətbiqi → Professional Dashboard → Sound Collection.
   Meta bu trekləri məhz IG/FB kontenti üçün lisenziyalayıb, telif iddiası olmur.

2. **Pixabay Music** — pixabay.com/music, Pixabay lisenziyası,
   kommersiya istifadəsinə icazə verir, atribut tələb etmir.

## Nə seçmək

- Instrumental, vokalsız (səsləndirmə ilə toqquşmasın)
- 30 saniyədən uzun
- Sakit, korporativ/motivasiyaedici ritm
- 10–15 trek kifayətdir — təkrarlanma hiss olunmur

Fayl adlarında azərbaycan hərfi işlətmə (`upbeat-01.mp3` kimi sadə adlar).
